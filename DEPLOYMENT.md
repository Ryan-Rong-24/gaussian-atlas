# GitHub Pages Deployment Guide

## Issues Fixed

The deployment issues you encountered were:

1. **404 errors for `/src/main.tsx` and `/favicon.ico`**: This happened because GitHub Pages wasn't correctly configured to serve the built files from the `docs/dist` directory.
2. **Missing `landing_page.mp4`**: The video is now included in the build output.

## Solution

I've set up a GitHub Actions workflow that automatically builds and deploys your site whenever you push to the `main` branch.

## Setup Instructions

### Step 1: Configure GitHub Pages

1. Go to your repository on GitHub: `https://github.com/ryan-rong-24/gaussian-atlas`
2. Click on **Settings** → **Pages** (in the left sidebar)
3. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions**
   - This will use the workflow file I created at `.github/workflows/deploy.yml`

### Step 2: Deploy

You have two deployment options:

#### Option A: Automatic Deployment (Recommended)

Just commit and push your changes:

```bash
cd /Users/ryanrong/Documents/GitHub/gaussian-atlas
git add .
git commit -m "Fix GitHub Pages deployment with video background"
git push origin main
```

The GitHub Actions workflow will automatically:
- Build the project
- Deploy to GitHub Pages
- Make your site available at: `https://ryan-rong-24.github.io/gaussian-atlas/`

#### Option B: Manual Build and Deploy

If you prefer manual control:

```bash
# From the repository root
cd docs
./deploy.sh
```

Then commit and push the changes.

### Step 3: Verify Deployment

1. After pushing, go to **Actions** tab in your GitHub repository
2. You should see a workflow run called "Deploy to GitHub Pages"
3. Wait for it to complete (usually takes 1-2 minutes)
4. Visit: `https://ryan-rong-24.github.io/gaussian-atlas/`

## Important Configuration

- **Base URL**: Set in `docs/vite.config.ts` as `base: '/gaussian-atlas/'`
- This ensures all asset paths are relative to `https://ryan-rong-24.github.io/gaussian-atlas/`

## Troubleshooting

### Build locally to test:

```bash
cd docs
npm run build
npm run preview
```

Then visit `http://localhost:4173/gaussian-atlas/` to test the built site locally.

### Common Issues

1. **404 errors**: Make sure GitHub Pages source is set to "GitHub Actions" in Settings
2. **Assets not loading**: Check that `base: '/gaussian-atlas/'` is in `vite.config.ts`
3. **Video not playing**: Ensure `landing_page.mp4` exists in `docs/public/video/`
